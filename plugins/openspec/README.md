# OpenSpec

OpenSpec workflow skills for Codex.

This plugin bundles the `opsx-*` workflow skills, the `opsxx-*` dependency and orchestration extensions, their supporting scripts, and the repository guard hooks used to keep OpenSpec changes coherent. Install it from the One-Person Labs plugin marketplace, then invoke skills with names such as `$opsx-propose`, `$opsx-apply`, or `$opsxx-finish`.
